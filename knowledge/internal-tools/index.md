# Internal Tools

Tools built and maintained by the platform team that serve the wider R&D organization. These are standalone applications and services — not Terraform modules.

Part of [VII - Platform Infrastructure](../platform-infrastructure.md).

## What each child page represents

A single tool with: what it does and what problem it solves, architecture overview, how to use it, and who maintains it.

## Tools

- [Env1 - Platform Services Hub](./env1.md) — private Terraform registry, service config editor, and MCP server.
- [SonarQube - Code Quality & Security Analysis](./sonarqube.md) — self-hosted static code analysis and quality gates.
- [Usain Bolt - E2E Test Automation Platform](./usain-bolt.md) — Playwright-based E2E test orchestration and dashboard.
- [Radio - Lambda Power Tuning](./radio.md) — self-hosted AWS Lambda Power Tuning with a web UI.
- [Naughty - Teams Notification Service](./naughty.md) — Adaptive Card notifications to Microsoft Teams.
- [MCP Remote Tools — AI Agent Configuration](./mcp-remote-tools.md) — how to configure AI agents against the remote MCP tools.
- [MCP Development](./mcp-development/index.md) — MCP development guides, steering, servers, and skills.
